# Webページ音声入力拡張機能 (Chrome Speech-to-Text)

ウェブページのあらゆる入力欄に、シンプルで直感的な音声入力機能を追加するChrome拡張機能です。ブログ記事の執筆、メールの作成、フォームへの入力など、様々な場面での文字入力を効率化します。

---

## ✨ 主な機能

*   **ワンクリック操作**: 画面右下のボタンから、いつでも音声入力を開始・停止できます。
*   **キーボードショートカット**: `Ctrl+Shift+.` (Macでは `Cmd+Shift+.`) で素早く起動できます。
*   **幅広い互換性**:
    *   通常のテキストボックス (`<input>`)
    *   テキストエリア (`<textarea>`)
    *   リッチテキストエディタ (Gmail, WordPressなど)

## 🚀 インストール方法

この拡張機能はまだChromeウェブストアに公開されていません。以下の手順で手動でインストールしてください。

1.  **リポジトリのダウンロード**:
    *   このページの上部にある緑色の「Code」ボタンをクリックし、「Download ZIP」を選択してファイルをダウンロードします。
    *   ダウンロードしたZIPファイルを解凍します。

2.  **Chromeに拡張機能を読み込む**:
    *   Google Chromeを開き、アドレスバーに `chrome://extensions` と入力して拡張機能管理ページに移動します。
    *   ページの右上にある「**デベロッパー モード**」のスイッチをオンにします。
    *   「**パッケージ化されていない拡張機能を読み込む**」というボタンが表示されるので、それをクリックします。
    *   ファイル選択ダイアログが開くので、先ほど解凍した**フォルダそのもの**を選択します。

これでインストールは完了です。ツールバーに拡張機能のアイコンが表示されます。

## 使い方

1.  文字を入力したいウェブページを開きます。
2.  画面右下に表示されるマイクの形をしたフローティングボタンをクリックするか、ショートカットキー (`Ctrl+Shift+.`) を押します。
3.  初めて使用するサイトでは、マイクの使用許可を求めるポップアップが表示されるので、「許可」をクリックしてください。
4.  ボタンが赤色に変わり、「音声入力中…」というステータスが表示されたら、マイクに向かって話してください。
5.  話した内容がリアルタイムでテキストに変換され、カーソルのある入力欄に挿入されます。
6.  もう一度ボタンをクリックするか、ショートカットキーを押すと音声入力が停止します。
